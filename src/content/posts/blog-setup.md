本文记录了我搭建这个博客的全过程，希望能给想建站的朋友一些参考。

## 技术选型

对比了三种主流方案：

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| WordPress | 生态成熟、后台好用 | 需要服务器、维护成本高 |
| Hexo | 简单、GitHub 免费托管 | 主题定制较麻烦 |
| Astro | 快、可定制性强、免费托管 | 需要一点前端知识 |

最终选择了 Astro，理由：**快**（纯静态、零 JS 依赖）、**免费**（部署到 Vercel/Netlify/GitHub Pages）、**内容友好**（直接写 Markdown）。

## 主题设计

参考了 Sakurairo 主题的樱花风格：

- 樱花粉渐变主色
- 卡片式文章列表
- 侧边栏（头像 / 归档 / 标签云 / 最新文章）
- 亮暗双主题切换
- Hero 区搜索框

## 部署

```bash
npm install
npm run build
```

把 `dist/` 目录部署到任意静态托管平台即可。

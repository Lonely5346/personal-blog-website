# 8月20日网站更新日志

8月20日，「苍の博客」正式上线。除了开站的第一篇文章，这一天还完成了一系列改版与架构升级，来一起看看都更新了什么 👇

## 🎉 网站正式上线

- 发布开站文章《[你好，世界](/posts/welcome/)》，正式和大家见面
- 站点信息全面真实化：站名定为「苍の博客」，作者「空门苍」，换上真实头像，并配置了 GitHub 与邮箱联系方式

## 📡 RSS 订阅升级

- RSS 源现在输出**完整文章内容**，订阅阅读体验更好
- 添加了 RSS 自动发现标签，浏览器地址栏可以直接识别订阅地址

## 🏗️ 架构与部署升级

- **主域名迁移**：博客正式域名改为 **`blog.lonely5346.cn`**
- **根域名导航页**：`lonely5346.cn` 改造成樱花风格导航页，卡片式聚合各子域名入口，后续可以很方便地扩展相册、项目等服务
- **自动部署完善**：博客与导航页各有一套 GitHub Actions 工作流，推送代码后自动构建并部署到 Cloudflare Pages（导航页项目支持自动创建，全新环境也能一键跑通）

## 📄 合规与版权

- 新增《[隐私政策](/privacy/)》页面，说明站点数据收集情况，符合《个人信息保护法》要求
- 新增《[版权与免责声明](/disclaimer/)》页面，明确原创内容版权与转载规范
- 两个页面已在博客页脚和导航页页脚加入链接

## ✂️ 内容整理

- 对早期内容做了取舍整理，让博客更聚焦于个人记录，后续文章会持续补充

## 🔭 下一步计划

- 扩展更多子域名服务（相册、项目等）
- 接入评论系统（giscus / Waline）
- 接入访问统计（Umami / 不蒜子）
